# Voorbeeld: prompt voor gedifferentieerde oefeningen

*Example of a full input and output (Dutch). The skill works the same way in English and French.*

## Input

> Maak een prompt om oefeningen te maken over breuken optellen voor het 5e leerjaar, op drie niveaus.

## Output

### De prompt

```
Je bent een ervaren leerkracht in het 5e leerjaar van het basisonderwijs in Vlaanderen.

Context: mijn leerlingen (10–11 jaar) leren breuken optellen. Ze kunnen al gelijknamige breuken optellen. Het leerdoel van deze les is: ongelijknamige breuken optellen door ze eerst gelijknamig te maken.

Opdracht: maak oefeningen op drie niveaus.
- Basis: 6 oefeningen waarbij één noemer een veelvoud is van de andere (bv. 1/2 + 1/4)
- Kern: 6 oefeningen met noemers zonder veelvoud (bv. 1/3 + 1/4)
- Uitdaging: 3 vraagstukken uit het dagelijks leven, waarvan één met een veelvoorkomende fout die de leerling moet opsporen

Vorm:
- Een tabel per niveau: oefening | oplossing | tussenstap
- Gebruik geen breuken groter dan 1 in het antwoord
- Schrijf de vraagstukken in eenvoudige taal

Stel me eerst één vraag als iets onduidelijk is.
```

### Invullen
Niets in te vullen; pas het leerjaar of het leerdoel aan als dat bij jouw klas anders is.

### Waarom dit werkt
- **Het leerdoel staat vooraan** → alle oefeningen sluiten erop aan, in plaats van een willekeurige mix.
- **Drie niveaus met een concreet voorbeeld per niveau** → de AI weet precies wat "makkelijker" en "moeilijker" betekent.
- **Een fout laten opsporen** → leerlingen moeten denken over de methode, niet alleen rekenen.
- **De tussenstap in de oplossing** → je kunt meteen zien waar een leerling vastloopt.

### Volgende stap
"Maak bij elk niveau een korte uitleg in kindertaal die ik op het bord kan zetten."
